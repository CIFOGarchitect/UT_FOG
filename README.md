**Version 4.0 — January 2027**
**Authority:** Statewide Interoperability Coordinator, under the direction of the Statewide Interoperability Executive Committee
**Published by:** Statewide Interoperability Coordinator, Utah Division of Emergency Management, Department of Public Safety (DPS/DEM)
**Supersedes:** Version 3.0 (November 2022)

## Distribution — read this first

**CONTROLLED — Controlled Unclassified Information (CUI). Authorized users only.**

This repository must remain **PRIVATE**. Do not make it public, do not publish any file from it to a public site (including GitHub Pages), and do not distribute its contents outside authorized users. This edition contains agency-restricted talkgroup data and operational communications information. If you are unsure whether someone is authorized, ask the Statewide Interoperability Coordinator before sharing.

## Status

This is a **working draft**. Section-level verification and currency notes are included in the draft itself — read the notes in any section before operational use. Content marked VERIFY is carried from an older source and must be confirmed before it is relied on.

## How to read it

1. Open `utfog-v4-preview.html` in any browser for the formatted guide with the clickable index.
2. Use the index at the top to jump to a section. Each section states its sources and any verification notes.
3. For the full talkgroup data, use the CSV files above (spreadsheet or database) rather than copying rows out of the preview page.

## How to update it

Edit `utfog-v4-working-draft.md`, then regenerate or update the preview page to match. Keep the two in sync: a change to one without the other leaves two versions of the guide that will drift apart. When a section's verification note is resolved, remove the note and record what confirmed it.
